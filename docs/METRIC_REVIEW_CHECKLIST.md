# Metric Review Checklist

Before publishing an asset KPI table, verify:

- [ ] All assets use comparable date windows.
- [ ] Prices are positive and sorted by date.
- [ ] Returns are computed within each asset.
- [ ] The first return per asset is null rather than zero.
- [ ] Annualized metrics state the 365-day convention.
- [ ] Drawdown is negative or zero.
- [ ] Sharpe-style ratios are not described as forecasts.
- [ ] The volume-based field is called a proxy.
- [ ] Assets with insufficient observations are flagged or excluded from ranking.
- [ ] Findings are described as sample-period observations.
