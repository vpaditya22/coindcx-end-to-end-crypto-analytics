# Analytics Assumptions and Limitations

- Daily crypto markets are treated as operating 365 days per year for annualization.
- The Sharpe-style ratio uses a 0% risk-free-rate assumption.
- Return and risk metrics describe only the downloaded observation window.
- Daily returns are calculated per asset from the preceding retained close.
- Correlation is descriptive and can change with the selected period.
- The close-times-volume measure is a proxy and must not be presented as verified exchange turnover unless the volume denomination is confirmed.
- Public market data does not reveal customer portfolios, customer-level profits, retention, churn, or CoinDCX revenue.
- Historical performance does not predict future performance.

Review these assumptions before presenting any chart, dashboard, or business recommendation.
