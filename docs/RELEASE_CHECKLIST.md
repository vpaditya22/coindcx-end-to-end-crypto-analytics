# Release Checklist

- [ ] Install runtime and development dependencies in a clean environment.
- [ ] Run the unit-test suite.
- [ ] Confirm pipeline commands and file paths in README match the repository.
- [ ] Review API response handling and current CoinDCX documentation.
- [ ] Check date coverage, duplicate rows and missing values.
- [ ] Confirm all charts have units, titles and a stated time window.
- [ ] Verify turnover is labelled as a proxy.
- [ ] Confirm no customer-level or revenue claims are inferred from market data.
- [ ] Check that raw extracts, database files, secrets and environment files are not staged.
- [ ] Update documentation for changed behavior.
