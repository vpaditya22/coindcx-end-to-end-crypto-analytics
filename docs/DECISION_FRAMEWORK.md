# Decision Framework

Use the analysis to frame questions rather than declare a single winning asset.

1. Compare assets over a common observation window.
2. Review return alongside volatility and drawdown.
3. Check the number of observations and missing-date patterns.
4. Review the liquidity proxy only with its unit caveat.
5. Check correlations before describing diversification.
6. Translate findings into testable product hypotheses, such as clearer risk education or recurring-investment discovery.
7. State which internal customer, order or product data would be required to validate a product hypothesis.

A market-data ranking alone cannot prove product-market fit or establish an investment recommendation.
