# Engineering Change Review Template

## Goal
What user-visible or analytical problem does the change solve?

## Implementation
Which modules, datasets, tables or dashboard views changed?

## Validation
Which unit tests, lint checks or reproducible commands were run?

## Data implications
Did units, date coverage, metric definitions or API behavior change?

## Risk
Could this change alter historical results or downstream schemas?

## Documentation
Which README, data dictionary or runbook sections need updating?
