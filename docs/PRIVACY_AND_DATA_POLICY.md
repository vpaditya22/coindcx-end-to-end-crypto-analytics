# Data and Privacy Policy

This project uses public market-level information and published aggregate business context. It does not require customer-identifiable data.

- Do not add private customer records, account identifiers, API keys, tokens or credentials.
- Keep local extracts ignored by Git unless redistribution is permitted by the source terms.
- Review CoinDCX API terms before publishing raw data or derived datasets.
- Keep claims traceable to either a reproducible market-data output or a clearly identified public report.
- Do not label market-level analysis as customer analytics.
