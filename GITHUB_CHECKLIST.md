# GitHub Publishing Checklist

## Before publishing

- [ ] Run the full pipeline
- [ ] Confirm the API works with current CoinDCX documentation
- [ ] Review CoinDCX API terms
- [ ] Do NOT commit API keys
- [ ] Do NOT commit customer/private data
- [ ] Do NOT commit raw CoinDCX market data if current terms restrict redistribution
- [ ] Keep the raw/processed data directories ignored if necessary
- [ ] Include screenshots of the dashboard
- [ ] Add a short project video/GIF if desired
- [ ] Explain that the data is reproducible through the API

## Recommended repository description

> End-to-end CoinDCX crypto market analytics project using real INR market data, Python ETL, risk/return KPIs, SQL, business analysis and a Streamlit dashboard.
